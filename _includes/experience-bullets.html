Parameters: items - a list where each item is either a string, or a map with `text` and optional `children` (another list of the same shape) Text is rendered as inline Markdown, so **bold**, `code`, and [links](https://example.com) work. {% endcomment %}

    ' | remove: '

    ' | strip }} {%- if item.children.size > 0 %} {% include experience-bullets.html items=item.children %} {%- endif %}
    • {%- else %}
  • {{ item | markdownify | remove: '

    ' | remove: '

    ' | strip }}
    • {%- endif %} {%- endfor %}
