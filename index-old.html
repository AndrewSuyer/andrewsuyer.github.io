Java Platform Runner

I made this game for my final project in AP Computer Science A, which I took in my junior year. It was quite a big project, probably bigger than what we were expected to do. It was one of my first experiences in making GUI's and windows. Looking back at it, I realize that there is a lot that I could have done better when It came to how I loaded textures and images. If you tried to download this game and play it yourself, you would probably see nothing because all the images are stored somewhere on my hard drive and not in the project directory.

Perhaps the most interesting thing about the development of this game is how I designed the levels. If you looked into the code, you would notice every block of every level is placed manually. I obviously didn't write the thousands of lines of code manually. Instead, I used google sheets to plan out each level, then I used a script to generate the code. Each block in the game is represented by a color in google sheets. When creating a level, I would draw it out (literally) in google sheets using the colors I defined.
