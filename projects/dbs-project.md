# Building a Database Application

This project involved designing a database for a wine management software system.


## Part 1: Database design

Given a set of requirements for the database, I helped make an **entity relationship diagram** 
using good design practices.

![dbs-project-erd](/assets/images/dbs-project/ERD-annotated.png)

After creating the ERD, my team proceeded to make a **relational schema** for the different 
entities, which subsequenty was translated into a set of DDL table definition statements.
